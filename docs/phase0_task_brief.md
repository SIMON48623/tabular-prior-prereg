# 任务简报：Phase 0 可行性检查 — 公开表格数据集的信号集中度分布

> 整份交给执行方。需要 Python 环境与网络（访问 OpenML）。
> 预计耗时：数小时。不需要 GPU。

---

## 0. 背景

我们在研究一个假设：**表格基础模型（TabPFN 一类）相对传统学习器的优势，取决于数据集的信号集中度**——信号高度集中在单一强变量上时优势消失，分散在多个弱变量上时优势出现。

定义**信号集中度 SCR**：

```
SCR = ( AUROC(最强单变量) − 0.5 ) / ( AUROC(参照全模型) − 0.5 )
```

取值 0 到 1。越接近 1，说明可达判别力越依赖单一变量。

［登记时删去一句：作者此前在一个临床队列中的探索性分析结果。该队列的数据和结果不属于本研究，见预注册第 10 节。］

**本次任务只回答一个问题：公开表格数据集的 SCR 分布，是否覆盖足够宽的区间（特别是 SCR>0.7 的高集中度一端），使得上述假设可被检验。**

覆盖得住，正式基准研究启动；覆盖不住，分层变量需要重新设计。

## 3. SCR 的计算 — 必须嵌套，这是本任务的技术核心

朴素做法有两处泄漏，都会系统性高估 SCR，必须避免。

**泄漏一：方向校正。**单变量 AUROC 若用 `max(a, 1-a)`，方向是在评估数据上选的。
**泄漏二：选最大值。**"最强单变量"若在全数据上选，存在选择偏倚（winner's curse），特征越多偏倚越大。

**正确流程**（分层五折，`StratifiedKFold(5, shuffle=True, random_state=42)`）：

对每个外层折 k：

1. 在**训练折上**，对每个特征 j 计算 AUROC，并确定方向（若 AUROC<0.5 则取反向）。
2. 在**训练折上**选出 argmax 的那个特征 j\*，记下它和它的方向。
3. 在**held-out 折上**，用 j\* 和训练折确定的方向计算该特征的预测值。
4. 同时在训练折上拟合逻辑回归（预处理全部在训练折内），对 held-out 折产出预测概率。

五折跑完后：
- `auc_best_feature` = 用**汇总的 held-out 预测**（步骤3产出）计算的 AUROC
- `auc_lr` = 用**汇总的 held-out 概率**（步骤4产出）计算的 AUROC
- `SCR = (auc_best_feature − 0.5) / (auc_lr − 0.5)`

**边界处理**：
- 若 `auc_lr ≤ 0.52`，该数据集判为"无可用信号"，SCR 记为 NaN 并标记排除，不参与分布统计。
- SCR 理论上可超过 1（单变量优于全模型），**不要裁剪**，如实记录。这类情况本身是有信息量的。
- 若 j\* 在不同折之间不一致，如实记录一致性（五折中 argmax 相同的折数），这是 SCR 稳定性的指标。

**预处理**（逻辑回归用）：数值列训练折中位数插补 + 标准化；类别列训练折众数插补 + one-hot（`handle_unknown='ignore'`）。全部在训练折内拟合。

**同时报告原始形式**：`auc_best_feature` 本身（不除以分母）。两种形式都要，正式研究再决定用哪个作为主分层变量。

## 4. 输出规格

在 `phase0_outputs/` 下产出：

### 4.1 `phase0_outputs/datasets_scr.csv`

每行一个数据集。列：

```
openml_id, name, version, n, p_raw, p_used, minority_rate,
n_dropped_missing_cols, n_dropped_id_cols,
best_feature_name, best_feature_fold_consistency,
auc_best_feature, auc_lr, SCR, excluded_reason
```

`excluded_reason` 为空表示纳入统计；被排除的数据集也要留在表里，注明原因。

### 4.2 `phase0_outputs/scr_distribution.md`

一份简短报告，包含：

- 纳入数据集数量、排除数量及各排除原因计数
- SCR 的描述统计：min / Q1 / 中位数 / Q3 / max
- **分箱计数**：SCR 落在 [0,0.3) / [0.3,0.5) / [0.5,0.7) / [0.7,0.9) / [0.9,∞) 各有多少个
- `auc_best_feature` 的同样统计
- SCR 与 n、p_used、minority_rate 的 Spearman 相关系数（用于检查分层变量是否被这些因素混淆）
- 直方图两张：SCR 分布、auc_best_feature 分布

### 4.3 `phase0_outputs/scr_hist.png`

SCR 分布直方图，标出上述分箱边界。

### 4.4 `phase0_outputs/run_log.txt`

每个候选数据集一行：openml_id、是否纳入、失败时的错误原因。下载失败、解析失败的也要记录，不要静默跳过。

### 4.5 `phase0_outputs/environment.json`

Python 版本、scikit-learn 版本、openml 包版本、随机种子、筛选规则的实际取值。

1. `datasets_scr.csv` 中 `excluded_reason` 为空的行，`SCR` 必须非 NaN 且 `auc_lr > 0.52`。
2. 随机抽 3 个数据集，手工验证：把流程改成"在全数据上选最强特征并校正方向"，得到的 `auc_best_feature` 应当**高于**嵌套流程的结果。若两者相同，说明嵌套没有真正生效，停下来检查。
3. 确认全程没有调用 TabPFN、CatBoost、XGBoost、LightGBM、RandomForest 或任何树模型。
4. 确认没有对 SCR 做裁剪。
